# 💧 HydroSync — Smart Water Bottle Website

## 📌 Project Overview

HydroSync is a modern product landing page for a smart water bottle designed to encourage better hydration. The website features a blue-themed background, a product display, a navigation bar, and interactive call-to-action buttons.

The website presents features such as hydration reminders, fitness wearable synchronization, and temperature insulation.

## ✨ Features

- **Modern Landing Page:** Clean layout with a blue-themed visual design.
- **Product Showcase:** Displays the HydroSync smart water bottle.
- **Navigation Bar:** Links to the Features, Specs, and Reviews sections.
- **Call-to-Action Buttons:** Shop Now and Pre-Order Today buttons navigate to the shopping section.
- **Feature Cards:** Highlights Smart Sync, Glow Reminders, and 24-hour Insulation.
- **Responsive Design:** Uses CSS media queries to adapt the layout to smaller screens.
- **Hover Effects:** Adds interactive styling to buttons, navigation links, and feature cards.
- **Shopping Cart Demo:** Includes JavaScript logic to track the number of items added to the cart.

## 🛠️ Technologies Used

- **HTML5** — Structures the webpage and its content.
- **CSS3** — Provides styling, gradients, layout, animations, and responsive design.
- **JavaScript** — Handles the shopping cart quantity and displays feedback when an item is added.
- **Flexbox** — Arranges the header, hero section, feature cards, and footer.
- **CSS Media Queries** — Adjusts the layout for smaller screens.

## ⚙️ Setup and Installation

Follow these steps to run the project locally.

1. Download or clone this GitHub repository.
2. Open the project folder.
3. Ensure the image files `bb.jpg` and `new.jpg` are in the same folder as the HTML file.
4. Save the website code in a file named `index.html`.
5. Open `index.html` in a web browser such as Google Chrome, Microsoft Edge, or Firefox.

No additional libraries or installations are required.
